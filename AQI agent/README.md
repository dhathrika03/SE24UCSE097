*Problem Statement-*

To design and implement a Simple Reflex Agent that determines the Air Quality Index (AQI) based on environmental pollutant data received from sensors.



*Agent Type-*

Simple Reflex Agent using if-else conditional statements.



*Input-*

The agent reads sensor values from a text file containing pollutant concentrations such as PM2.5, PM10, CO, NO2, SO2, O3, and NH3.



*Working of the code-*

1\. Read pollutant values from input file

2\. Then Compare each value with predefined AQI thresholds

3\. Apply if–else rules to determine AQI category

4\. Display AQI result



*Output-*

The system outputs the AQI category such as Good, Moderate and poor.



*Tools \& Technologies-*

\- Python3

\- File handling

\- Conditional statements(if-else)



*Project Structure-*

\- code/ → Python source code

\- input/ → Sensor data file

\- README.md → Documentation



*Conclusion-*

This project demonstrates the working of a Simple Reflex Agent(AQI) by comparing the input files data with the main AQI thresholds and  gives the AQI defined category with file readings(output).
